# Microsoft Teams

Contacts Portal supports Teams tabs and two messaging extensions. Each guide
describes one feature:

- [Personal and customer tabs](teams-tabs.md)
- [Teams sign-in and Microsoft Graph](teams-authentication.md)
- [Customer search and call-summary bot extension](teams-bot-extension.md)
- [Contact Cards API extension](teams-contact-cards.md)
- [App setup and deployment](teams-deployment.md)

Use the [manifest packaging guide](../teams/README.md) to build the two Teams
app packages.
